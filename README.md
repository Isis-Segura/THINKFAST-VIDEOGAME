## **¿Qué es TINKFAST?**

**TINKFAST!** es un videojuego educativo diseñado especialmente para niñas y niños en etapa escolar. Su objetivo es reforzar conocimientos básicos de una forma divertida, accesible y motivadora.

Más que un repaso, es una experiencia de aprendizaje interactiva que combina *juego + conocimiento*.

---

## 🎓 **Nuestro Compromiso Social — ODS 4**

Este proyecto se alinea con el **Objetivo de Desarrollo Sostenible #4: Educación de Calidad**. Fue creado por estudiantes comprometidos en ofrecer una herramienta didáctica basada en investigación y pedagogía infantil.

# ▶️ **Guía para Ejecutar el Juego**

### 1️ **Clona el repositorio:**

```bash
git clone https://github.com/Isis-Segura/THINKFAST-VIDEOGAME.git
cd THINKFAST-VIDEOGAME
```

### 2️ **Instala pygame:**

```bash
pip install pygame
```

### 3 **Instala ffplayer:**

```bash
pip install ffplayer
```
### 4 **Instala MediaInfo:**

```bash
pip install MediaInfo
```
### 5 **Ejecuta el juego:**

```bash
python menu.py
```
